## Included

- Automatic claiming of earned Twitch Drops and Channel Points.
- Background live playback with manual pause and mute controls preserved.
- Claim history, statistics, and configurable alerts.
- Manifest V3 runtime and restart-safe background handling.

## Install

Download the extension ZIP attached below, extract it, then use **Load unpacked** in `chrome://extensions` to select the `automatic-twitch-manifest-v3` folder. Refresh Twitch after loading.

To replace an existing installation, extract the new files into the same extension folder and click **Reload** in Chrome.

The `.sha256` asset contains the ZIP's SHA-256 checksum. Original authorship and applicable notices are included in the package.
